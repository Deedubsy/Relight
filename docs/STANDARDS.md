## The five that decide the category (day-one dealbreakers, from `reception.md`)

1. **Blueprints and copy-paste, or a visible plan for gating them.** The loudest launch complaint on FOUNDRY (18 review mentions), Satisfactory, DSP, Factory Town, ShapeHero and Techtonica; forgiven only where the gate is visible. **Placed 2026-09-04 (layout pass, unverified):** the survivor panel's first row from minute one reads "Blueprints and copy-paste · a survivor's gift (Phase 7) — not yet found" (`panel.ts`, GA-EF-3); Phase 7 replaces it with the survivor. **Closed by D-P5-4 (2026-09-05):** §14, §19 and §24 no longer promise blueprints from minute one, so the panel's row is now the only statement the game makes about them — the gate is visible from minute one, which is the condition this dealbreaker is forgiven under. Phase 5 builds the bot's blueprint *file* (a harness JSON), not the item.
2. **A goal after the first problems are solved.** "Mid-game slog" is the most common negative-review theme across FOUNDRY, Desynced, Techtonica, Captain of Industry (35 mentions), Astro Colony and shapez 2. A design point, not a UI one — E17 measures it.
3. **Deletion that is safe** — confirmation or undo, and a full refund. DSP's launch month (65- and 92-reply threads), Captain of Industry (8 threads), Satisfactory; Satisfactory's refund-plus-timer is the forgiven pattern; Sandustry is punished for "no refund on deletion".
4. **Performance at launch.** Binary: Techtonica (34 mentions) and Astro Colony (25) were marked down for it, no game was praised for it.
5. **Onboarding that teaches the core loop and the quality-of-life keys.** A tutorial that doesn't teach the loop (Astro Colony 34, Captain of Industry 44, Desynced, FOUNDRY's "forced tutorial") and hidden QoL (Captain of Industry's R / F found "after 25 hours", Mindustry's `[` `]` and F6, Sandustry) are the same failure in reviews.

Runners-up: belt drag placement (press, day one) and production statistics.

## The five they'd forgive at launch

1. **Multiplayer** — three of seven references ship without it; requested, never a dealbreaker.
2. **Mod support** — every reference has it eventually; none was punished for lacking it at launch.
3. **Controller and Steam Deck** — forgiven unless the store page over-promises; only Factorio has native support.
4. **Pipette** — forum-only requests; never a review theme.
5. **Localisation quality** — mocked (DSP "just enough off", ShapeHero's machine translation), not punished; absence of a language is a store-page filter, not a review.
