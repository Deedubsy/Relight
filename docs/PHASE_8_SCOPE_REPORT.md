## Implementation acceptance

These definitions specify the increments in PROGRESS, not another status list. Costs and bounded technical defaults remain provisional until recorded with implementation evidence.

**P8-01 — Foreman and working clipboard.** Add stable reachable local Foreman recruitment with a real copy/paste capability in the same increment. Capture selected complete machine footprints and supported settings; give a visible clipboard and destination preview, rotation/mirror, explicit cancellation and honest locked/invalid feedback. Placement uses ordinary paid commands, current unlocks, footprint/terrain/occupancy rules, reach and material limits. State whether a stamp is atomic or retains completed paid work on failure; feedback/history must match that choice. Source/copy is read-only. Keep valid settings and conserved undo/redo. Verify multi-tile machines, splitters, underground pairs, filters/recipes/freight, insufficient stock/reach and older-save/full-command replay. Validate that recruitment cannot duplicate rewards or move existing saved sites.

**P8-02 — library and ghost orders.** Save bounded named/foldered/icon-tagged blueprint entries and portable validated import/export data. Reject malformed, oversized, overlapping or unsupported plans before mutation. Add a visible saved order queue with stable IDs and explicit waiting/cancelled/completed states; a plan can be placed before its materials are in hand. Show missing quantities and current blockers. Ghosts remain inert until ordinary manual construction or the later truck executor pays for real machines; repeated/cancelled orders cannot duplicate construction. No import bypasses Foreman or machine unlocks. Partial progress, removal of a library entry and save/load retain a coherent independent order definition.

**P8-03 — physical Line truck executor.** Let the player select a physical supply chest and queued work after recruiting Foreman. Validate local loading, real available stock and cargo capacity; move along a footprint-valid street route, then construct only within a declared local service reach from its cargo. Loading and placement account for identical material costs and existing packed machines. Display loading/travelling/building/waiting state and specific shortages, full cargo, blocked route, vanished source or occupied destination. Recheck current conditions rather than trusting a stale route or reservation. Bound retries without teleporting or spinning; resume after a fix. Pause/cancel/manual takeover leave actual stock aboard and paid machines in place. Save/replay midway through loading, movement and partial construction must not double-spend, clone or lose items. Reuse shared construction rules without changing the engineer’s inventory or position to impersonate a builder.

**P8-04 — removal and order management.** Add explicit area selection and preview for manual machine removal, using existing packing eligibility, current reach and available capacity. Define transaction size, partial failure and undo behaviour visibly and test loaded belts/tunnels, turrets with loose rounds, busy machines, cargo and settings. Retain installed facilities/core protection. Provide clear queue pause/resume/retry/cancel and source selection controls; repeated actions are idempotent. Exercise interruption by new obstructions, source depletion/removal, changed destinations and switching between manual and automatic truck control. Compare ordinary paid placement commands against the same layout using the tools, recording time/materials/failures and assistance; command savings alone are not human tedium evidence.

**P8-05 — integration and engineering review.** Build useful repeated ammunition/supply/defence patterns from ordinary stock, including a station-supported source chest and working powered/output-connected results. Test seeds 3/4/5 and holdouts 8/11/13, alternate recruitment/build orders and a declared broader placement/route sweep. Include valid/blocked truck turns, congested streets, depletion, capacity, load/replay/migration and live threat coexistence. Verify conservation across every source chest, truck, pockets, constructed machine and paid/refunded sink. Run full required code/profile checks and browser controls at 1366/900 widths, including keyboard focus/cancellation and responsive status. Measure normal light/power edits with the tools open and retain known stalls/reference-machine gaps. Review each acceptance row without substituting automation for human observations.
