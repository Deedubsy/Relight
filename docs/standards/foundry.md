# FOUNDRY (Channel 3 Entertainment / Paradox Arc) — standards audit reference

Status as of 2026-09-04: still Early Access (EA 2024-05-02); Update 1 "Cable & Creations" 2024-08-13, Update 2 "Galactic Commerce" 2025-05-11, Update 3 experimental 2025-12-15, Update 4 "Rails & Reactors" 2026-04-28; no 1.0 date announced. Sources: [Steam store](https://store.steampowered.com/app/983870/FOUNDRY/), [Update 1](https://www.paradoxinteractive.com/games/foundry/news/update-1-cable-and-creations-is-here), [PCGamesN U2](https://www.pcgamesn.com/foundry/update-galactic-commerce), [U3 thread](https://steamcommunity.com/app/983870/discussions/0/685240346634996250/), [U4 notes](https://www.bisecthosting.com/blog/foundry-update-4-release-date-patch-notes-new-features-changes), [FAQ](https://www.paradoxinteractive.com/games/foundry/faq).

## 1. Controls
- First-person — WASD, mouse look, jump/sprint; jetpack is a researched item (Jetpack Fuel occupies inventory) — [wiki Controls](https://wiki.foundry-game.com/index.php/Controls), [Steam thread](https://steamcommunity.com/app/983870/discussions/0/4361250551850063518/)
- Rotate — R/T/H rotate on Y/X/Z axes in build mode; X toggles build mode; Shift+X "Toggle Drag Mode"; hold RMB opens the modify menu — [wiki Controls](https://wiki.foundry-game.com/index.php/Controls)
- Snap vs free — free mode no longer persists; defaults to snap when equipping a building — [Dev Blog 23](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-23-the-usability-patch)
- Mirror — not found
- Pipette — "Copy Target" (Ctrl+C) copies the target building with its settings and rotation; F picks an item off a belt — [wiki Controls](https://wiki.foundry-game.com/index.php/Controls), [Dev Blog 23](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-23-the-usability-patch)
- Drag/line placement — hold LMB to place multiple blocks; "smart conveyor drag mode" added in Update 2; loaders being reworked to drag start-to-end with direction inferred (DevBlog #107, not shipped) — [beginner guide](https://www.bisecthosting.com/blog/foundry-beginners-guide-new-player-tips-tricks), [Leo's Life U2](https://marcleoseguin.com/2025/05/14/foundry-update-2/), [Steam news feed](https://store.steampowered.com/feeds/news/app/983870/)
- Ghost placement — placeholders exist; whether blueprints place ghosts for drones is an open design question ("Gamify or not gamify?", DevBlog #109, 2026-08-07) — [Steam news feed](https://store.steampowered.com/feeds/news/app/983870/)
- Undo/redo — none; players still request it (Dec 2025 suggestions thread, "UNDO !!!" on the U3 experimental thread); recovery is via autosave — [discussion search](https://steamcommunity.com/app/983870/discussions/search/?q=undo&gidforum=0), [rage-quit thread](https://steamcommunity.com/app/983870/discussions/0/4362375983955452534/)
- Copy/paste — "Configuration Copy/Paste" of settings for machines, loaders, pipe loaders, balancers; Ctrl+RMB/LMB copy/paste recipe in tablet mode — [Dev Blog 23](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-23-the-usability-patch), [wiki Controls](https://wiki.foundry-game.com/index.php/Controls)
- Blueprints — not shipped; WIP preview shows copy/paste of machine groups with rotation, works with workstations/trains; the community used the "Duplicationer" mod meanwhile — [DevBlog #109](https://store.steampowered.com/news/app/983870/view/699898252573540646), [Steam news feed](https://store.steampowered.com/feeds/news/app/983870/), [Roadmap](https://www.paradoxinteractive.com/games/foundry/roadmap); library/sharing — not found
- Upgrade tool — not found
- Deconstruction/area select — Z demolition mode, Ctrl+Z bulk demolition; the drag box is 3D, which caused accidental floor deletions; dimensions shown top-centre — [wiki Controls](https://wiki.foundry-game.com/index.php/Controls), [rage-quit thread](https://steamcommunity.com/app/983870/discussions/0/4362375983955452534/)
- Hotbar/paging — slots 1–0, Ctrl+1–0 selects hotbars, Tab/Shift+Tab cycle hotbars; nothing-equipped state allowed — [wiki Controls](https://wiki.foundry-game.com/index.php/Controls), [Dev Blog 23](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-23-the-usability-patch)
- Rebinding — "Keyboard controls can be rebound in the Controls Settings"; F3/F4/Alt+Enter fixed — [wiki Controls](https://wiki.foundry-game.com/index.php/Controls)
- Controller — Steam lists "Partial Controller Support"; default layout lacks demolish, no glyphs/prompts, players rebind via Steam Input (threads May–Oct 2025) — [steambase](https://steambase.io/games/foundry/info), [controller thread](https://steamcommunity.com/app/983870/discussions/0/601903738647480319/)
- Steam Deck — Steam "Playable"; ProtonDB Platinum (30 reports); ~30 fps default, 50–60 with lowered shadows/clouds — [steambase](https://steambase.io/games/foundry/info), [ProtonDB API](https://www.protondb.com/api/v1/reports/summaries/983870.json), [FAQ](https://www.paradoxinteractive.com/games/foundry/faq)

## 2. Logistics affordances
- Belts — single-lane tiers I–IV; Conveyor I 160 items/min; separate Conveyor Slope items per tier; Escalators for elevation — [wiki Conveyor I](https://wiki.foundry-game.com/index.php/Conveyor_I), [wiki page list](https://wiki.foundry-game.com/api.php?action=query&list=allpages&aplimit=500&format=json)
- Auto-corner — at EA launch curves had to be placed manually ("manually stick a curved piece"); improved by U2 smart drag — [Game8](https://game8.co/articles/reviews/foundry-review-early-access), [Leo's Life U2](https://marcleoseguin.com/2025/05/14/foundry-update-2/)

- Splitters/priority — Conveyor Balancer merges up to 2 belts, front/back switches set preferred input/output or balance; balancers locked behind alternate research, criticised — [wiki Balancer I](https://wiki.foundry-game.com/index.php/Conveyor_Balancer_I), [Leo's Life U2](https://marcleoseguin.com/2025/05/14/foundry-update-2/)
- Loaders — Loader, 2nd-lane and 3rd-lane variants; Filter Loader 1800 items/min, 5 kW; 3rd-row loader "arrives too late" — [wiki Filter Loader](https://wiki.foundry-game.com/index.php/Filter_Loader), [Leo's Life U2](https://marcleoseguin.com/2025/05/14/foundry-update-2/)
- Vertical — Freight Elevator I–III (U2 upgrades praised); 1x1 conveyor lifts planned (DevBlog #108/#110) — [Steam news feed](https://store.steampowered.com/feeds/news/app/983870/)
- Hover throughput — parts/min shown on machine screen panels, not on belts; "what's on this belt" — not found; F picks an item off a belt with a hint after watching a belt — [PPM thread](https://steamcommunity.com/app/983870/discussions/0/4343240135700801960/), [Dev Blog 23](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-23-the-usability-patch)

## 9. Performance expectations
- Late-game counts — community base of ~100,000 pieces went 10 fps to ~90 fps before EA (DevBlog #51) — [DevBlog #51](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-51-performance-and-feature-highlights)
- Sim/render — simulation in native C++ via P/Invoke, "Unity & Custom C++ Backend"; factories "CPU bound" so effects moved to GPU; 50–150% fps gain in dense areas (DevBlog #63); screen panels atlased, 27→32 fps (DevBlog #70) — [Dev Blog 3](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-3-performance-challenges), [wiki Foundry](https://wiki.foundry-game.com/index.php/Foundry), [DevBlog #63](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-63-more-optimization), [DevBlog #70](https://www.paradoxinteractive.com/games/foundry/news/dev-blog-70-scaling)
- U4 — reduced server memory, faster research; large-save load times flagged as needing work — [U4 notes](https://www.bisecthosting.com/blog/foundry-update-4-release-date-patch-notes-new-features-changes), [Steam news feed](https://store.steampowered.com/feeds/news/app/983870/)

UI and default binds — "blocky", "clunky" inventories, "default bindings just don't make sense", controls "seriously terrible"; no controller glyphs — [Game8](https://game8.co/articles/reviews/foundry-review-early-access), [top reviews](https://steamcommunity.com/app/983870/reviews/?l=english&browsefilter=toprated), [controller thread](https://steamcommunity.com/app/983870/discussions/0/601903738647480319/)

Post-U4: trains "too cumbersome and not intuitive", poorly documented; power system confusion; belts stalling from logistic containers — [recent reviews](https://steamcommunity.com/app/983870/reviews/?browsefilter=mostrecent&l=english), [Steam news feed](https://store.steampowered.com/feeds/news/app/983870/), [r/FoundryGame](https://www.reddit.com/r/FoundryGame/comments/1w3xqt4/broken_belts_or_logistics_containers/)
