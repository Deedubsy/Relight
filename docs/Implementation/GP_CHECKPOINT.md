### Power connection corrections — 2026-09-11

Owner diagnosis request: “does a new building automatically connect to the closest pole? the pole always shows no power; the power icon is always on the map”, followed by “I like those” plus two more asks (a placement preview of what a Pole would link to, and a sane HUD power reading with no Generator). Root causes found by headless reproduction on a fresh campaign:

- **Connection was automatic but the Generator’s reach was shorter than the guidance.** `campaignGrid` linked node-to-node (Pole/Big pole/Generator/Substation) by centre-to-centre distance ≤ reach, while a consuming machine joined by centre-to-footprint distance. A 2×2 Generator therefore linked a Pole only across a 6-tile orthogonal / 4-tile diagonal gap; a machine linked across 7. A Pole placed “within 8 tiles” of the Generator never linked, so every Pole chained from it truthfully reported no supply.
- **Pole and Generator ghosts previewed nothing.** Only kW-drawing machines showed the network hint.

The HUD power line fell back to that circuit and read “112 / 0 kW”.

Corrections (GP-POWER-FIX):

- **Link rule.** `nodesLinked`: a reach node links to another node when its centre lies within its reach of that node’s footprint, in either direction — the same rule machines use. Pole-to-Pole spacing is unchanged in practice (centre within 8 of the other Pole’s tile); the Generator now links across the same 7-tile gap as an Excavator. Networks are numbered per block in creation order (“Home network 1” is the block substation, “Home network 2” the first Generator circuit) instead of by internal node index.
- **Placement preview.** `powerLinksAt(st, kind, x, y, size)` (sim, read-only) lists every Pole, Big pole, Generator or Substation a Pole/Big pole/Generator ghost would cable to, or the one node a consuming machine would join. `worldScene` draws purple (`#b388ff`) lines from the ghost centre to each node with a dot at the far end, and the cursor reason reads “links Generator, Pole · supplied” / “no fuelled source on it yet” / “nothing in reach: no Pole, Generator or Substation within 8 tiles” / for a Generator “no Pole in reach yet: chain Poles from it”. Nothing is drawn when nothing would link.

- **Outage semantics.** `BaseCore.poweredAt` records the first sim time the base’s block circuit carried supply (`tickBasePower`, each campaign tick). `campaignOutages` reports a base only when it is disabled or has been powered before and now has no supply. A new game therefore shows no outage strip or minimap marker until power has actually been lost. Once a base has carried supply the legacy event and its 20 s “Power back” rule apply unchanged; the legacy profile has no `campaign` and is untouched.
