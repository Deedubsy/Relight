## Retained scope and implementation boundaries

Phase 5 keeps start-unlocked machines and its transport systems. Add the start-unlocked 1×2 splitter and paired 1×1 underground endpoints; the current `Machine.size` and footprint tables assume squares, so occupancy, reach, rendering and saves must consistently support rectangular machines before a splitter or 2×3 truck is called complete; retain one lane and one inserter with an optional single-item filter (D-P5-2/3/5). The intended underground span is four tiles; its exact distance convention, endpoint pairing, buffering and removal behaviour must be documented before implementation, with boundary tests. Prices and capacity defaults must be labelled task assumptions, not inferred balance approvals.

Fast belts are a Foundry unlock, Assembler Mk2 has an unresolved purchase/unlock, and Concrete/Shell/Fuel/Polymer need later machines or facilities. Keep those explicitly later with RI-10/11 and EX-09; their recipe data does not make them Phase 5 production chains. Cannon, Mixer, Pumpjack, Refinery, Line truck automation, Foreman delivery assistance and the player blueprint clipboard are also later. D-P5-4 retains a harness blueprint file now and found construction assistance later. No automatic underground conversion or new inserter tier is implied.

Factory placement remains free-roaming campaign placement under Q01 with local physical power, real inventories and collision/reach checks. D-CU-1's Held/interior alternatives do not reimpose old campaign territory restrictions. C3/D-B2-2 remain provisional historical decisions; keep a human acknowledgement/reversal at the phase exit rather than claiming the owner signed them during this audit. Likewise D-SA-2 permits the provisional string-table work already scheduled but its human sign-off remains outstanding; translations and a rebinding settings screen belong to later release/interface scope.

Construction undo must compensate only the selected construction action using current inventories and reach; it must not rewind time, combat, production, discovery or restoration. Changes to occupied/damaged machines, contents, full pockets, intervening edits and removed tram infrastructure require safe refusals or conserved inverse operations with a visible explanation. Replaying the command stream and loading a save must not apply an inverse twice. Define history persistence and grouping before the code increment; implementation defaults are reversible.

Truck rules retain the existing intended street travel, physical 2×3 footprint, 200-stack vehicle storage, three-times-walk speed and ordinary engineer reach from the seat. Those inherited values are provisional for the campaign. The old depot unlock does not automatically grant an extra vehicle with Q04's specified starter kit. The owner selected the restored second-area tram station in D-EX-Q08 during this audit. Make the persistent truck available there after restoration; it is not a machine item inserted into the starter kit. Q08 is decided and Q07 does not block this increment. No new fuel chain is introduced by this task.
