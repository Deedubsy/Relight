# Phaser city authoring

Open `packages/game/src/editor/RiverfrontCity.scene` in Phaser Editor. See [the workflow](../../docs/PHASER_EDITOR.md).

- `manifest.json` binds native editor UUIDs to canonical building IDs and preserves the starting layout. Do not edit by hand.
- `RiverfrontCity.source.txt` is the current CITY-F baseline canonical source for deterministic application/restoration and source-drift checks. Keep it with the manifest.
- `last-apply.json` records the last successful import and previous source hashes; generated by Apply.

Save the scene, run `npm run editor:check`, then `npm run editor:apply`, reload the live preview on port 5190 and start a New Game. No runtime editor library is required. Existing saves keep their layout identity.

Current baseline: 479 buildings plus editable `PLOT_` rectangles. New background roofs and plot edits import through validation; campaign/interior anchors remain fixed. The prior approved neighbourhood is retained in `docs/evidence/city-density/`; the earlier pre-density backups remain in `docs/evidence/neighbourhood-density/`.
