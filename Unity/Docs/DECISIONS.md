# Decisions — Unity migration

This file is the migration's decision record. It holds three kinds of entry, kept apart:

- **Confirmed owner decisions** that the Unity port must honour. Each entry names its provenance in the reference project. The reference `docs/DECISIONS.md` and `docs/EXPLORATION_DEFENCE_PLAN.md` §6.3 remain the historical record; this file records what carries over and does not rewrite them.
- **Migration choices** made by the coordinator with justification. These are engineering choices, not gameplay approvals, and the owner can overturn them.
- **Owner questions**, each marked resolved, awaiting external information, or deferred to the phase where it becomes answerable (§4). Two remain open: U-Q-02 (the ending) and U-Q-04 (the art package and tileset licence).

Status labels used across the package: **Implemented and retained** / **Approved but not implemented** / **Implemented but needs correction** / **Unresolved** / **Retired**. Numbers are tagged **current** (in code today), **approved** (explicitly confirmed by the owner) or **provisional** (chosen for the checkpoint, may change).

Related: [GAME_DESIGN.md](GAME_DESIGN.md) for the experience these decisions shape, [CONTENT_CATALOGUE.md](CONTENT_CATALOGUE.md) for the values, [MIGRATION_MAP.md](MIGRATION_MAP.md) for per-system disposition, [TASKS.md](TASKS.md) for status.

| U-M-01 | **Target: Unity 6.6 (6000.6) with UI Toolkit for all runtime UI.** Unity 6.6 is an *Update* ("Supported") release, not an LTS release: Unity's release-support page lists 6.3 LTS (supported until December 2027) and 6.0 LTS as the LTS lines, and 6000.6.0f1 was released on 31 August 2026 as an Update release (earlier wording "Unity 6.6 LTS" in this package was wrong and is withdrawn). Update releases are supported with bug fixes and critical platform updates only until the next release (update or LTS) is published, against two years for an LTS; the trade-off is a sooner upgrade decision, not a capability gap (`unity.com/releases/unity-6/support`). B-01 records the exact editor version actually installed and used (`6000.6.x`), the package versions, and any deviation. **No silent version change:** if 6.6 cannot be installed or a package is unavailable on it, B-01 reports that and the owner decides; the coordinator does not switch to another version on its own. | The owner asked for Unity 6.6 and UI Toolkit.
